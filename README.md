# 🚀 UPSC InsightX

> An AI-Powered Smart Learning Platform for UPSC Aspirants

UPSC InsightX is an intelligent learning platform designed to transform traditional UPSC preparation into a personalized, data-driven, and engaging experience.

The platform combines AI assistance, quizzes, analytics, current affairs, interactive maps, gamification, and comprehensive study materials into one unified ecosystem.

# 🚀 Installation

Clone repository

```bash
git clone https://github.com/Gnanasupriyabairynayanikadiri/InsightX-UPSC.git
```

Install packages

```bash
pip install -r requirements.txt
```

Run

```bash
streamlit run app.py
```
